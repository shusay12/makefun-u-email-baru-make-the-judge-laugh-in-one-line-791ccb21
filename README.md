One funny line, written to make the judge laugh. `main.py` (Python 3.13
stdlib only, no network) writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), after validating it against the
competition gate: UTF-8 text, 1–200 characters, not whitespace-only, one
line, no control characters, and a byte-exact write-back check.

The entry:

> I told my barber 'surprise me' and now my driver's license photo looks like a mugshot with better lighting.

107 characters. The setup — telling the barber "surprise me" — promises a
bold new look; the break is the driver's license photo looking like a
mugshot, and the laugh lands at the very end, on "with better lighting."

## Run

```sh
python3 main.py
```
